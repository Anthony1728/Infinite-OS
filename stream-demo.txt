=== KEY RULES ===
1. First status event fires in <100ms — before the model is even warm.
2. First real token arrives in <200ms — that's the "time to first byte" target.
3. Subsequent chunks arrive every 50–150ms — never empty gaps longer than that.
4. provider_status + message_start happen BEFORE any text_delta.
5. The UI never sits silent for more than ~200ms once a request is sent.

=== WHAT THIS MEANS FOR YOUR UI ===
- The "Thinking…" caption should switch to "Calling openrouter/llama-3.3" the
  instant provider_start fires (~50ms after click).
- It should switch to "openrouter is streaming" the instant the HTTP 200 lands.
- The first text_delta should swap the bubble for the real message — the
  ThinkingBubble disappears, the assistant message appears.
- If you wait >300ms between text_delta chunks during normal streaming, the
  user feels "it's stuck again" even though work is happening.
